# Dungeon of Death

**Dungeon of Death** is a 2D pixel-art soulslike RPG that follows the journey of a fallen knight betrayed and trapped in a mysterious realm between life and death. The player must fight through dangerous dungeon floors, overcome brutal enemies, and escape the cursed dimension.

## Technical Details

* **Engine:** Godot Engine 4.x
* **Language:** GDScript
* **Genre:** 2D Soulslike RPG
* **Art Style:** Pixel Art
* **Platform:** PC (Windows / Linux)
